# Contributing

DAD is a v0.1 methodology, so the most valuable contributions are reports from real use.

- **Tried it on a project?** Open an issue with what worked, which phase broke down and why.
- **Disagree with a decision?** Open an issue that names the section of `docs/methodology.md` and proposes an alternative.
- **Templates, schemas, commands or `dad-check`:** pull requests welcome. Run `npm run check:example` before opening one.

Changes to the methodology itself go through an issue first, so the reasoning is recorded before the text changes.
