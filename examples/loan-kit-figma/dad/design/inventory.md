## How to read this inventory

- **Maps to** uses business entity names proposed by the agent. Because no layer is named `@Entity.field`, every mapping below is an inference from visible text; the ones that depend on an unanswered question carry its ID.
- **Node** is the Figma node id of the text layer. `Ixx;yy` ids are layers inside component instances. For Login/Register and Shop the text came from screenshots after the MCP limit; the node id is the text layer when metadata identified it, otherwise the nearest container (marked *container*).
- Fields that repeat on several screens are mapped on each screen, so the designer can check every occurrence.
- "Rules stated in copy" are not designer annotations (the file has none). They are on-screen sentences that state a rule, copied verbatim.
